深挖情报workflow

# 一句话
AI扮演情报分析员，从选定的公司公告出发，多轮自主检索、提取风险事实，形成公司风险画像，人工一键转为研究线索。

# 业务流程
step 1: qwen3.8-max-0902: 结合目标公司信息 + 已提取的事实 + 联网搜索结果，自主判断需求证的内容，如公司新闻、风险诉讼、业绩展望，等等。

step 2: program: 跨语言检索内部公告库求证。

step 3: qwen3.8-max-0902: 从检索到的原文里提取风险事实，每条事实必须引用原文出处

step 4: qwen3.8-max-0902: 判断证据是否足够，证据不足从step 1开始循环。

step 5: qwen3.8-max-0902: 汇总全部事实，输出公司风险画像（风险时间线 + 风险分类 + 与平台信号对照）

step 6: human: 查看风险画像，可一键转为研究线索，进入研究立项流程

# 亮点
1. 自主检索：AI 自己决定查什么、查几轮，证据够了就收手；
2. 结论有出处：每条风险事实都引用公司公告原文；
3. 跨语言：中文、英文、法文公告都能检索；
4. 直达研究：风险画像一键转为研究线索，衔接研究迭代流程。
