# Factopia AI 能力清单

| 能力 | 页面 | 触发方式 | 用途 | 模型 |
|---|---|---|---|---|
| AI 默认假设 | 线索池 | 提交线索时选“投资假设 / 研究员经验 / 人工反馈”，打开表单即自动生成；点「换一个」重新生成，或填写“你的想法”后点「按想法生成」 | 自动给出一条可编辑的研究假设，供研究员修改后提交。 | LLM Pro |
| AI 研究假设 | 线索池 | 打开监控预警、模拟盘、组合归因、审批退回等自动回流的线索时自动生成，无需点击 | 把平台自动产生的记录改写成可检验的研究假设。 | LLM Lite |
| AI 调研 | 线索池 | 点选一条线索，点卡片上的「AI 调研」 | 自动查找平台内外证据，判断线索能否立项；能立项就起草研究规格，不能就说明证据缺口和建议。 | LLM Pro（“暂不可立项”结论用 LLM Lite） |
| AI 合并 / 追加假设 | 线索池 | 勾选 2 条以上线索，点「AI 合并为一个研究假设」；或选择已有研究后点「AI 合成追加假设」 | 把多条线索合成一个可检验的研究假设，或把新线索追加到已有研究形成新版本。 | LLM Pro |
| 论文因子抽取 | 线索池 | 提交线索时选“论文 / 研报”，点「提交线索」后自动抽取；详情页可点「抽取候选因子」或「重新抽取」 | 从论文或研报中找出可用平台数据检验的因子，附原文出处，并标出数据不可得的因子。 | LLM Pro |
| AI 查询 | 线索池 | 在右侧线索列表的搜索框输入问题，点「AI 查询」 | 按意思而不是只按关键词查找历史线索。 | LLM Lite（轻量检索） |
| AI 搜索 | 研究项目 | 展开“历史项目”，输入关键词，点「AI 搜索」 | 按意思查找历史研究项目。 | LLM Lite（轻量检索） |
| AI 起草研究规格 | 研究立项 | 填好假设和范围，点「AI 起草研究规格 →」 | 把研究想法和授权条款起草成完整研究规格（研究计划、候选方向、验证方法），并把授权书中的文字条款解释成研究约束。 | LLM Pro |
| 联网检索 | 研究立项 | 在“外部资料检索”输入关键词或留空，点「联网检索」 | 联网查找回测期之前的公开资料，作为研究立项的参考。 | LLM Pro |
| AI 起点因子构想 | 研究立项 | 在“起点因子”选择因子或填写描述，点「让 AI 提构想 →」 | 从因子库已有因子出发，提出变体或组合的研究构想，供研究员选用。 | LLM Pro |
| AI 解释市场差异 | 结果 | 在“AI 解释市场差异”面板点「生成解释」 | 解释同一信号在不同市场表现不同的原因，每句都引用平台事实，不改变平台结论。 | LLM Pro |
| AI 研究迭代 | 结果 / 研究 Agent | 在结果页点「继续研究 ▾」→「AI 生成下一版假设（vN）并自动运行」；可勾选“联网”“深度思考” | AI 根据本轮结果诊断问题、制定计划、独立评审并生成下一版研究假设，人工批准后自动运行和评估。 | LLM Pro |
| AI 公告风险标注 | 情报台 | 打开“公告与打分”查看；结果由后台生成，无需点击，在“语言专家复核”确认或修正 | 自动判断公告段落的风险类别、方向和置信度，并生成中文、英文、法文译文。 | LLM Pro |
| 公告深挖 | 情报台 | 在“公告与打分”点某条公告的「公告深挖」，或打开公告后点「以本篇为起点深挖」，再点「启动深挖」 | AI 自动决定查哪些公告、提取风险事实，形成一家公司的风险时间线和结论，可转为线索。 | LLM Pro（查询改写和“数据不足”结论用 LLM Lite） |
| AI 摘要 | 情报台 | 在“跨语言检索”检索后，点「生成摘要」 | 把检索结果概括成带原文引用的摘要。 | LLM Pro |
| 术语表扩充 | 情报台 | 在“术语表”查看「AI 找到的候选术语」（候选由后台生成），点「批准」或「拒绝」 | 从术语表没覆盖的公告说法中找出漏掉的风险表述，生成候选术语，批准后加入术语表。 | LLM Lite |
| 知识检索 | 因子库 | 在“知识检索”勾选“大模型改写提问”，输入问题后点「检索」 | 把提问改写成中文、英文、法文关键词，帮助跨语言查找因子、研究和公告。 | LLM Lite |
